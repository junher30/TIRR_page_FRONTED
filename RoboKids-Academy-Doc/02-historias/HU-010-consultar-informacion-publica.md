# HU-010 — Consultar información pública

**Estado:** Borrador derivado de RF; pendiente de validación.  
**Actor:** Visitante público.  
**Requisitos:** RF-007, RF-017, RF-049–RF-055.

## Historia

Como visitante quiero consultar eventos, categorías, equipos, reglamentos, agenda y resultados sin iniciar sesión para seguir el campeonato.

## Criterios de aceptación derivados

1. El visitante consulta eventos, reglamentos, resultados, clasificaciones y transmisiones sin autenticarse.
2. La agenda publicada muestra pista, hora, orden de participación y rivales.
3. Las llaves muestran rondas, cruces, clasificados y próximos encuentros.
4. Los marcadores se actualizan en tiempo real sin recargar la página.
5. Se ofrecen vistas adecuadas para pantallas de exhibición.
6. El historial incluye resultados anteriores, podios, ganadores y estadísticas.
7. El sistema puede integrar videos o emisiones de plataformas externas.

## Pendiente

> PENDIENTE: Frecuencia/latencia de actualización, datos públicos versus privados y plataformas de transmisión admitidas.
