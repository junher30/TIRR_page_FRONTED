# HU-005 — Inscribir equipos

**Estado:** Borrador derivado de RF; pendiente de validación.  
**Actor:** Capitán / Coach autenticado.  
**Requisitos:** RF-013, RF-015, RF-019–RF-020, RF-027.

## Historia

Como Coach autenticado, quiero inscribir mis equipos en categorías disponibles y conocer el importe calculado para completar su participación.

## Criterios de aceptación derivados

1. Solo una cuenta autenticada con rol Capitán / Coach puede crear una inscripción.
2. El sistema registra los datos de equipo, integrantes, institución, país, categoría y contacto requeridos.
3. El servidor calcula el precio con base en equipos y categorías seleccionados.
4. La inscripción respeta fechas, cupos y requisitos configurados para la categoría.
