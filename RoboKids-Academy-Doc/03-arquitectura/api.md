# API

No se proporcionó contrato API, tecnología de transporte, esquema de autenticación ni convenciones de errores. Este archivo reserva el espacio para el contrato y evita inventar rutas.

## Áreas que requieren contratos

- Identidad, cuentas y permisos (RF-001–RF-010).
- Campeonatos, categorías, sedes, equipos e inscripciones (RF-011–RF-020).
- Tarifas, órdenes, pagos, webhooks y comprobantes (RF-021–RF-031, RF-083–RF-087, RF-090).
- Credenciales y registro de accesos (RF-032–RF-039, RF-088–RF-089).
- Reglamentos, llaves, encuentros, puntuaciones, resultados y apelaciones (RF-040–RF-048).
- Consultas públicas y actualizaciones en vivo (RF-049–RF-058).
- Asistente y escalamiento (RF-056–RF-063).
