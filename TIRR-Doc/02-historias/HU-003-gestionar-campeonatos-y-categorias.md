# HU-003 — Gestionar campeonatos y categorías

**Estado:** Borrador derivado de RF; pendiente de validación.  
**Actor:** Administrador de eventos.  
**Requisitos:** RF-004, RF-011–RF-015.

## Historia

Como administrador de eventos, quiero configurar campeonatos, ediciones, categorías, cupos, sedes, horarios y periodos de inscripción para preparar competencias simultáneas.

## Criterios de aceptación derivados

1. Se pueden crear y modificar varios campeonatos, ediciones y eventos.
2. Una categoría puede definir modalidad, edad, integrantes permitidos, cupo, precio y requisitos.
3. Se pueden gestionar ubicaciones, pistas, mesas, jornadas y rondas.
4. Las inscripciones pueden abrirse, cerrarse, suspenderse o ampliarse, con fechas límite modificables.
