# HU-013 — Usar herramientas de administración

**Estado:** Borrador derivado de RF; pendiente de validación.  
**Actor:** Administrador autorizado.  
**Requisitos:** RF-002, RF-075–RF-080.

## Historia

Como administrador quiero disponer de herramientas acordes con mi rol para buscar, comunicar, exportar y revisar la operación de los eventos.

## Criterios de aceptación derivados

1. Menús y herramientas se adaptan a permisos del usuario.
2. La identidad visual permite gestionar logotipos, patrocinadores, colores e imagen de evento.
3. Se pueden filtrar equipos, categorías, competidores, eventos y resultados.
4. Se envían notificaciones de inscripciones, pagos, acreditaciones y cambios de horario.
5. Se generan informes Excel, CSV y PDF.
6. Se consultan estadísticas de participantes, países, ingresos, cupos y estado de competencias.

## Pendiente

> PENDIENTE: Catálogo de plantillas/canales, consentimiento para notificaciones, filtros, permisos de exportación y definición de cada indicador.
