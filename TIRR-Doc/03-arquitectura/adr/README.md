# Architecture Decision Records (ADR)

No se proporcionaron decisiones arquitectónicas registradas. No se crean ADR retroactivos ni se presume que las tecnologías mencionadas estén aprobadas.

Convención propuesta para futuras decisiones: `ADR-NNN-titulo.md`, con estado (propuesta, aceptada, rechazada, reemplazada), contexto, decisión, alternativas, consecuencias, fecha y responsables.

> PENDIENTE: Registrar y validar las decisiones necesarias sobre stack, proveedor de pagos, despliegue, archivos, autenticación, API y servicio de IA.
